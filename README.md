# Chune Evans Kihonji — Portfolio

Personal portfolio for **Chune Evans Kihonji**, Civil Engineer (University of Nairobi, class of 2026) and Data Scientist based in Kenya.

## Tech Stack
- **Architecture**: Single Page Application (SPA) with smooth gradient wipe transitions
- **Styling**: Modern CSS variables, custom typography (Space Grotesk, Inter, JetBrains Mono), responsive design, and glassmorphism
- **Interactive Features**:
  - Interactive HTML5 canvas particle network
  - 3D card tilt effects
  - Dynamic blog category filtering
  - Interactive right-side background portrait with custom conic and radial masks
  - Direct form submission via FormSubmit AJAX with mailto fallback
  - One-click email copy with instant feedback

## Deploying on Vercel
1. Import this repository (`Eltons-gt/ChuneEvansPortfolio`) on [Vercel](https://vercel.com).
2. Framework Preset: **Other** (Static HTML).
3. Root Directory: `./`
4. Click **Deploy**.
